# Нативная работа на Mac с Apple Silicon

Окружение использует Apple Clang 21 из Command Line Tools и CMake 3.31.
Оба инструмента уже установлены. Бинарники собираются для ARM64 и запускаются
прямо в macOS. Дополнительные пакеты для сборки не нужны.

В корне репозитория добавлен отдельный CMake-адаптер для занятий **1.1–1.3**.
Он собирает исходники из `project/src/` и подключает оригинальные тесты курса.
Исходная сборка в `project/`, тесты и код заданий не изменены.

## Сборка, тесты и запуск

Все команды выполняются из корня `mipt_cpp_course`, а не из `project/`:

```sh
cmake --preset macos-arm64 -D NANO_EDR_LESSON=1.1
cmake --build --preset macos-arm64 --parallel
ctest --preset macos-arm64
./project/build/macos-arm64/nano-edr project/scenarios/phishing_macro.log
```

Номер занятия хранится в кэше. При переходе на 1.2 или 1.3 повторите первую
команду с новым номером. Реализации функций занятия добавляются самостоятельно
в `project/src/`; без них новые тесты могут не скомпоноваться.

Исходная заготовка 1.1 только считает строки. Три теста запускаются, но падают
из-за отсутствия детектов и поддержки `--quiet`. Это ожидаемый результат
до выполнения задания, а не ошибка окружения.

Строгая сборка и проверка памяти:

```sh
cmake --preset macos-arm64-strict -D NANO_EDR_LESSON=1.1
cmake --build --preset macos-arm64-strict --parallel
ctest --preset macos-arm64-strict

cmake --preset macos-arm64-asan -D NANO_EDR_LESSON=1.1
cmake --build --preset macos-arm64-asan --parallel
ctest --preset macos-arm64-asan
```

ASan и UBSan проверяют обращения к памяти и неопределённое поведение.
На macOS этот режим не заменяет проверку утечек на Linux.
Номер занятия задаётся отдельно для каждого пресета.

## VS Code

Откройте папку `mipt_cpp_course`. Локальные настройки `.vscode/` уже созданы;
расширения Microsoft C/C++ и CMake Tools уже установлены.

- Выберите configure-пресет `macos-arm64` в CMake Tools.
- `Cmd+Shift+B` собирает проект.
- Задача `ARM64: test` собирает проект и запускает тесты; они также доступны
  через CMake Tools в панели Testing после конфигурации.
- `F5` запускает отладку LLDB с выбором сценария и предварительной сборкой.
- Навигация использует `project/compile_commands.json`, обновляемый сборкой.

Настройки `.vscode/` исключены из Git правилами курса.

## Ограничение комплекта

Начиная с занятия 2.1 нужен симулятор `os`/`edr`. Его исходников в репозитории
нет, а готовые библиотеки поставлены только для Windows x64 и Linux x64.
Нативный адаптер останавливает конфигурацию таких занятий с пояснением.
Для полного курса на macOS ARM64 нужно получить у преподавателя библиотеки
`libos.dylib` и `libedr.dylib` для macOS ARM64, а также ARM64-версии инструментов
`sim_verify` и `gen_stress`, после чего подключить их к сборке.
