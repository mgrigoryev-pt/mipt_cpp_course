# Программирование на языке C++

Материалы курса Высшей школы программной инженерии МФТИ: пятнадцать лекций
обязательной базы и двенадцать практических занятий одного сквозного проекта.

Целевой стандарт — **C++23**. Примеры проверены на `g++ -std=c++23 -Wall
-Wextra`; для сборки нужен g++ 14+ или clang 19+.

Компилятор, CMake и VS Code с нуля — под Windows и под Linux — ставятся
по [`SETUP.md`](SETUP.md). Там же настройка редактора: пресеты, номер занятия,
запуск и отладка агента, тесты в панели Testing.

## Как читать

Каждая лекция — пара файлов в `lectures/NN/`:

- **`slides.md`** — слайды, которые показываются на занятии. Формат
  [Marp](https://marp.app/): открываются в VS Code расширением «Marp for
  VS Code» либо экспортируются в PDF.
- **`lecture.md`** — конспект того же материала для самостоятельного чтения.
  Не пересказ слайдов: он подробнее объясняет «почему так» и связывает тему
  с остальными лекциями.

Файлы дополняют друг друга. Слайды без конспекта оставляют вопрос «а почему
именно так», конспект без слайдов — «а что здесь главное».

Экспорт в PDF, если удобнее читать так:

```bash
npx @marp-team/marp-cli lectures/01/slides.md --pdf
```

## Программа лекций

| № | Тема |
|---|---|
| 1 | Введение, базовые типы, control flow, `namespace`/`using`, препроцессор, CE/RE/UB |
| 2 | Память и указатели, `new`/`delete`, односвязный список, RAII, знакомство с `unique_ptr`/`shared_ptr` |
| 3 | Функции, ссылки, `const`, касты, как функция сообщает об ошибке, `noexcept` |
| 4 | Введение в ООП: классы, конструкторы, деструкторы, designated initializers |
| 5 | Перегрузка операторов, правило трёх, `<=>`, функторы, `[[nodiscard]]` |
| 6 | Наследование: модификаторы, layout, порядок конструкторов, ромб, virtual-наследование |
| 7 | Полиморфизм: виртуальные функции, `override`/`final`, абстрактные классы, `dynamic_cast`, `enum class` |
| 8 | Шаблоны: синтаксис, инстанцирование, CTAD, специализация, non-type параметры |
| 9 | Variadic templates, fold expressions, правила вывода типов |
| 10 | Лямбды, захваты, `std::function`, трамплин для C-API |
| 11 | Move-семантика: `std::move`, value categories, правило пяти и нуля, RVO |
| 12 | `auto` и `decltype`: правила вывода, `decltype(auto)` |
| 13 | Итераторы, стандартные контейнеры, structured bindings, алгоритмы |
| 14 | `string_view`, `span`, `optional`, `variant`, `expected`, обработка ошибок |
| 15 | Умные указатели изнутри, `weak_ptr`, основы многопоточности |

Порядок не случаен: классы идут одним цельным блоком (4–7), шаблоны — другим
(8–9), а лямбды (10) стыкуют их через идею «лямбда — это автогенерируемый
шаблонный функтор». Тем не хватало вкраплений друг в друга, и от них избавились
сознательно.

## Практикум

Параллельно курсу идёт сквозной проект — агент, который получает поток событий
от операционной системы, коррелирует их правилами и реагирует.
Постановки всех двенадцати занятий и трёх проверочных — в
[`practice/`](practice/README.md): что делать на паре, что дома, по какому
критерию занятие считается закрытым. Каждое занятие опирается на конкретную
лекцию и ссылается на неё.

Заготовка проекта, границы, симулятор собранными библиотеками, сценарии
и выдаваемые тесты — в [`project/`](project/README.md). Он собирается
из внутреннего репозитория курса скриптом, а не правится здесь руками.

Курс читают разработчики Endpoint Security, поэтому часть примеров в лекциях
взята из этой области. Курсом по кибербезопасности он от этого не становится:
домен нужен, чтобы на вопрос «где это реально применяется» был конкретный ответ,
а не абстрактный.
