# Дополнительные материалы

Здесь лежит то, что не входит в пятнадцать лекций обязательной базы, но помогает
их понять: разборы механизмов, которые лекция вынуждена пройти коротко, и темы,
до которых у курса не доходят руки.

Материалы **необязательные** и на парах не читаются: ни один из них не нужен,
чтобы сдать практикум. Читаются в любой момент и в любом порядке — каждый
самодостаточен, а лекции, на которые он опирается, названы в начале текста.

Формат — только конспект: `notes.md` в своей папке, схемы рядом в `img/`.
Слайдов нет — материал для чтения, а не для показа на паре.
