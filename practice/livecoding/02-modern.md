# Лайв-кодинг «Шаблоны и современные механики»

Одна программа — `modern.cpp`, — которая растёт маленькими шагами. Каждый шаг
добавляет одну конструкцию языка, и после каждого программа собирается без
предупреждений и печатает то, что указано в его «Проверке».

Шаг записан блоком комментария. Скопируйте его целиком и вставьте
в `modern.cpp` над тем местом, где будете писать: компилятору комментарий
не мешает, а условие остаётся перед глазами рядом с кодом. Начните с шапки —
она идёт в самое начало файла.

Блоки 1–2 опираются на лекцию 9, блоки 3–5 — на лекцию 11, блок 6 —
на лекцию 12.

## Шапка

```cpp
// Лайв-кодинг: шаблоны и современные механики шаг за шагом
//
// Вы пишете одну программу — `modern.cpp` — маленькими шагами. Каждый шаг
// добавляет одну конструкцию языка, и после каждого программа собирается без
// предупреждений и печатает то, что указано в «Проверке».
//
// В «Проверке» — только то, что шаг добавил или изменил. Остальной вывод
// остаётся прежним. Адреса вида `0x1ec27558bf8` у каждого свои: совпадать
// должно только то, какие из них одинаковые.
//
// Имена берите из задания. По ним преподаватель сверяет код.
//
// Сверьте вывод сами и переходите дальше. Преподаватель подойдёт и посмотрит
// код. Если вывод не совпал или программа не собирается дольше двух-трёх минут
// — позовите его.
//
// С шага 9 программа ставит опыты с копиями. Каждый опыт — отдельный блок
// `{ ... }` в `main`, и первой строкой он печатает свой заголовок, например
// `-- swap`. Объекты опыта разрушаются на закрывающей скобке блока, поэтому
// его строки `free` не смешиваются со следующим опытом.
//
// Файл лежит отдельно от проекта nano-edr. Сборка и запуск на Windows:
//
//     clang++ -std=c++23 -Wall -Wextra modern.cpp -o modern.exe
//     modern.exe
//
// На Linux:
//
//     clang++ -std=c++23 -Wall -Wextra modern.cpp -o modern
//     ./modern
//
// Поля классов и структур инициализируйте в объявлении фигурными скобками:
// `int pid{};`, `std::string name_{};`.
```

## Блок 3. Копии на виду

### Шаг 9. Пачка событий

```cpp
// Шаг 9. Пачка событий
//
// Объявите `class Batch` — пачку событий, которая владеет массивом. Приватные
// поля — `Event* data_` и `std::size_t size_` (заголовок `<cstddef>`).
// Публичное:
// - конструктор `explicit Batch(std::size_t size)` выделяет `new Event[size]`
//   и печатает `alloc` и адрес массива, `static_cast<void*>(data_)`;
// - деструктор печатает `free` и адрес, затем освобождает массив `delete[]`;
// - копирующий конструктор выделяет свой массив того же размера, печатает
```
