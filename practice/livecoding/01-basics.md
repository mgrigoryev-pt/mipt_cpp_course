# Лайв-кодинг «База»

Одна программа — `live.cpp`, — которая растёт маленькими шагами. Каждый шаг
добавляет одну конструкцию языка, и после каждого программа собирается без
предупреждений и печатает то, что указано в его «Проверке».

Шаг записан блоком комментария. Скопируйте его целиком и вставьте в `live.cpp`
над тем местом, где будете писать: компилятору комментарий не мешает,
а условие остаётся перед глазами рядом с кодом. Начните с шапки — она идёт
в самое начало файла.

Блоки 1–6 опираются на лекции 1–8, блок 7 — на лекцию 10.

## Шапка

```cpp
// Лайв-кодинг: база C++ шаг за шагом
//
// Вы пишете одну программу — `live.cpp` — маленькими шагами. Каждый шаг
// добавляет одну конструкцию языка, и после каждого программа собирается без
// предупреждений и печатает то, что указано в «Проверке».
//
// В «Проверке» — только то, что шаг добавил или изменил. Остальной вывод
// остаётся прежним. Адреса вида `0x1ec27558bf8` у каждого свои: совпадать
// должно только то, какие из них одинаковые.
//
// Имена берите из задания. По ним преподаватель сверяет код.
//
// Сверьте вывод сами и переходите дальше. Преподаватель подойдёт и посмотрит
// код. Если вывод не совпал или программа не собирается дольше двух-трёх минут
// — позовите его.
//
// Файл лежит отдельно от проекта nano-edr. Сборка и запуск на Windows:
//
//     clang++ -std=c++23 -Wall -Wextra live.cpp -o live.exe
//     live.exe
//
// На Linux:
//
//     clang++ -std=c++23 -Wall -Wextra live.cpp -o live
//     ./live
//
// Поля классов и структур инициализируйте в объявлении пустыми фигурными
// скобками: `int pid{};`, `std::string name_{};`.
```
