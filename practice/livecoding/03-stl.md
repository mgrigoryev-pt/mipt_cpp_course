# Лайв-кодинг «Стандартная библиотека»

Одна программа — `stl.cpp`, — которая растёт маленькими шагами. Каждый шаг
добавляет одну конструкцию языка или стандартной библиотеки, и после каждого
программа собирается без предупреждений и печатает то, что указано в его
«Проверке».

Шаг записан блоком комментария. Скопируйте его целиком и вставьте в `stl.cpp`
над тем местом, где будете писать: компилятору комментарий не мешает,
а условие остаётся перед глазами рядом с кодом. Начните с шапки — она идёт
в самое начало файла.

Блоки 1–4 опираются на лекцию 13, блоки 5–7 — на лекцию 14.

## Шапка

```cpp
// Лайв-кодинг: стандартная библиотека шаг за шагом
//
// Вы пишете одну программу — `stl.cpp` — маленькими шагами. Каждый шаг
// добавляет одну конструкцию языка или стандартной библиотеки, и после
// каждого программа собирается без предупреждений и печатает то, что указано
// в «Проверке».
//
// В «Проверке» — только то, что шаг добавил или изменил. Остальной вывод
// остаётся прежним.
//
// Имена берите из задания. По ним преподаватель сверяет код.
//
// Сверьте вывод сами и переходите дальше. Преподаватель подойдёт и посмотрит
// код. Если вывод не совпал или программа не собирается дольше двух-трёх минут
// — позовите его.
//
// Файл лежит отдельно от проекта nano-edr. Сборка и запуск на Windows:
//
//     clang++ -std=c++23 -Wall -Wextra stl.cpp -o stl.exe
//     stl.exe
//
// На Linux:
//
//     clang++ -std=c++23 -Wall -Wextra stl.cpp -o stl
//     ./stl
//
// Поля структур инициализируйте в объявлении пустыми фигурными скобками:
// `int pid{};`, `std::string image{};`.
```
