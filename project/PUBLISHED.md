# Чем собран этот комплект

Каталог `project/` **собирается скриптом** из внутренних материалов
курса, а не правится руками. Правка здесь потеряется при следующей
публикации, поэтому свой код держите в `src/` — он не перезаписывается.

| | |
|---|---|
| версия внутренних материалов | `d36a512` |
| библиотеки win-x64 | edr.dll edr.lib os.dll os.lib |
| библиотеки linux-x64 | libedr.so libos.so |
