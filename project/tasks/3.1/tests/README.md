# Тесты занятия 3.1

Кольцевой буфер, пороговое правило, комбинаторы на шаблонах, типизированный
доступ к полям.

## Как подключить

```bash
cmake --preset windows -D NANO_EDR_LESSON=3.1
cmake --build --preset windows
ctest --preset windows
```

На Linux вместо `windows` — `linux`. Правки в вашем `CMakeLists.txt` не нужны:
тесты линкуются с библиотекой `nano_edr_core`, а она собирается сама из всех
`.cpp` в `src/`, кроме `main.cpp`.

Наборы занятий 2.1 и 2.3 остаются подключёнными и обязаны проходить. Кольцевой
буфер заменил список **в агенте**, но сам список остался в коде — на нём
построен примитив занятия, — и его тесты продолжают работать.

## Что проверяется

Требования, против которых собраны тесты, стоят в постановке занятия
(`practice/3.1.md`): публичный интерфейс `RingBuffer`, обход в логическом
порядке, «не аллоцирует вообще», три границы порогового правила и три его
свойства, пустые комбинаторы. Здесь они не повторяются, чтобы не разойтись
с постановкой.

Своего заголовка у `RingBuffer` и `MakeRule` в комплекте нет — их пишет
студент целиком, а тесты собраны против интерфейса, названного в постановке.

**Одна деталь про «не аллоцирует».** Проверяется это на `Timestamp`,
а не на `Event`: у события внутри строки, они аллоцируют сами по себе,
и утверждение о буфере на нём не проверить.

## Мост между статикой и динамикой

Комбинатор на шаблонах не реализует `ICondition` и не должен: реализовав,
он потерял бы ровно то, за чем создан — отсутствие виртуальных вызовов внутри.

Поэтому есть `MakeCondition`, который заворачивает любой вызываемый объект
в `ICondition`. Виртуальный вызов остаётся **один** — на весь составной
комбинатор, а не на каждое условие внутри.

## Типизированный доступ

`FieldTraits<T>` объявлен, но не определён — только специализации. Попытка
взять поле как тип, для которого разбора не написано, **не должна собираться**.
Молча сделать что-то похожее на правду хуже, чем не собраться.

Канал отказа не изменился с занятия 1.3: `false`, если поля нет или оно
не разбирается. Битые внешние данные — обычное дело, а не исключение.
