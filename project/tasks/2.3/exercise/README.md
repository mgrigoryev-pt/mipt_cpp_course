# Примитив занятия 2.3: диспетчеризация

Сорок минут. Смысл — увидеть, что виртуальный вызов не магия: это ровно та
таблица указателей на функции, которую вы соберёте руками, плюс один указатель
в объекте.

После этого фраза «виртуальный вызов стоит одну косвенность» перестаёт быть
заклинанием, потому что косвенность будет видна в собственном коде.

## Порядок работы

```bash
g++ -std=c++23 -O2 -Wall -Wextra -o dispatch dispatch.cpp
./dispatch
```

На Windows — из «x64 Native Tools Command Prompt for VS 2022», чтобы `cl` был
на `PATH`:

```
cl /std:c++latest /O2 /W4 /EHsc dispatch.cpp
dispatch.exe
```

**Замер имеет смысл только в Release.** В отладочной сборке ничего не встроено,
и обе версии одинаково медленные — сравнивать будет нечего.

## Что предсказать до запуска

### 1. Размеры

`ManualShape` хранит указатель на таблицу и два `int`. `Square` хранит один
`int` и наследует от класса с виртуальными функциями.

Предскажите `sizeof` для `ManualShape`, `Shape`, `Square`, `Rect`.

Вопрос по существу: **сколько байт в объекте занимает virtual?** Ответ должен
получиться из сравнения `sizeof(Square)` и «один `int` плюс что-то».

### 2. Невиртуальный деструктор

Раздел 4 создаёт наследника через указатель на базу и удаляет его. У базы
деструктор **не** виртуальный.

Предскажите, что напечатает счётчик. Потом объясните, почему компилятор
не сказал об этом ни слова.

В настоящем коде на месте счётчика была бы память, и её утечку показал бы
санитайзер. Здесь счётчик, чтобы результат был виден без санитайзера.

### 3. Замер

Миллион вызовов через ручную таблицу и миллион через `virtual`.

Предскажите: **что быстрее и во сколько раз?**

Прежде чем смотреть на числа, запишите свой ответ. Потом объясните
полученный — объяснение здесь важнее числа.

## Ожидаемые вопросы

- Почему таблица одна на «класс», а не одна на объект? Что было бы, если бы
  каждый объект хранил свою?
- В ручной версии `area` принимает `self` явным первым параметром.
  Куда он девается в версии с `virtual`?
- `ManualCall` делает три шага: разыменовать таблицу, взять указатель, позвать.
  Сколько из них делает `shape->Area()`?
- Что в ручной версии проверяет компилятор, а что нет? (Например: можно ли
  случайно положить в таблицу квадрата функцию площади прямоугольника?)

## Готово, когда

Предсказание по размерам совпало, поведение невиртуального деструктора
объяснено, а результат замера объяснён — независимо от того, совпал ли он
с предсказанием.

Про замер: если ваше объяснение звучит как «virtual медленнее, потому что
косвенность», проверьте его числами. Скорее всего оно не подтвердится, и это
самое полезное, что можно вынести из этого примитива.
