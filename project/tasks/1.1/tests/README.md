# Тесты занятия 1.1

Три случая, по одному на сценарий: `phishing_macro`, `ransomware`,
`clean_office`. Каждый запускает вашего агента на журнале событий и сравнивает
вывод детектов с эталоном побайтово.

## Как подключить

Тесты появляются при конфигурации, отдельной правки `CMakeLists.txt`
не требуется:

```bash
cmake --preset windows -D NANO_EDR_LESSON=1.1
cmake --build --preset windows
ctest --preset windows
```

На Linux вместо `windows` — `linux`. Тесты запускают цель `nano-edr`; если
ваша называется иначе, задайте имя через `NANO_EDR_AGENT`.

При расхождении тест печатает первую разошедшуюся строку — с неё и начинайте.

## Что именно проверяется

Тесты сравнивают вывод команды

```
nano-edr <журнал> --quiet
```

Под `--quiet` агент печатает только детекты и ничего больше. Формат детекта,
список признаков и правило про их порядок — в постановке занятия
(`practice/1.1.md`); здесь они не повторяются, чтобы не разойтись с ней.

Сравнение побайтовое. Перевод строки нормализуется: на Windows `stdout`
в текстовом режиме отдаёт `CRLF`, и скрипт прогона это учитывает. Всё
остальное — включая пробелы — обязано совпадать.
