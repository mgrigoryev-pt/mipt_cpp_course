# Тесты занятия 2.1

Пять групп: событие с инвариантом, разбор строки, окно событий, условия-функторы
и обёртка над границей `os.h`.

## Как подключить

```bash
cmake --preset windows -D NANO_EDR_LESSON=2.1
cmake --build --preset windows
ctest --preset windows
```

На Linux вместо `windows` — `linux`. Правки в вашем `CMakeLists.txt` не нужны:
тесты линкуются с библиотекой `nano_edr_core`, а она собирается сама из всех
`.cpp` в `src/`, кроме `main.cpp`.

Заготовки берутся из среза **`l2.1`**, и наборы занятий 1.2 и 1.3 сюда уже
не входят: против этого среза они бы не собрались. Это не поломка, а содержание
занятия: `Event` стал классом, разбор отдаёт `EventParts` вместо `Event`,
список стал классом с инвариантом. Проверять новые типы старыми тестами
нечем — тесты заменены, а не потеряны.

Тестам обёртки нужен настоящий журнал: проверяется, что конструктор бросает
на битом сценарии и не бросает на исправном. Путь к каталогу `scenarios/`
передаёт сборка тестов, делать для этого ничего не надо.

## Что проверяется

Требования, против которых собраны тесты, стоят в постановке занятия
(`practice/2.1.md`): инвариант вместо проверки после создания, разделение
«перевозчик — тип с обещаниями», единый формат у `operator<<`, `ToString`
и `std::format`, настраиваемое условие вместо функции. Здесь они
не повторяются, чтобы не разойтись с постановкой.

## Обязательно прогнать под санитайзером

Два случая — «тысяча элементов освобождается деструктором» и «на исправном
журнале хендл создаётся и освобождается» — под обычной сборкой не проверяют
почти ничего. Они и не должны: утечку видит не тест, а санитайзер.

```bash
cmake --preset asan -D NANO_EDR_LESSON=2.1
cmake --build --preset asan
ctest --preset asan
```

Незакрытый `os_handle*` — утечка, и именно так она и обнаруживается.

## Чего тесты не проверяют, но спросят на паре

**Трамплин.** Граница `os.h` принимает указатель на функцию и `void*`. Метод
класса указателем на функцию не является: у него есть неявный `this`. Поэтому
подписываются статическим методом, а объект передают через `void*`.

Трамплин обязан быть `noexcept` и обязан ловить внутри всё: раскрутка стека
через кадры C — неопределённое поведение. Тестом это не поймать (в отладочной
сборке симулятор заметит и завершит программу, но полагаться на чужую проверку
вместо своей — плохая привычка), а на паре спросят обязательно.

**Почему хендл нельзя копировать.** `os_handle*` — владеющий ресурс, за которым
стоит открытый файл, поток и отчёт. Две обёртки над одним указателем позвали бы
`os_free` дважды. Проверка на копируемость в тестах есть, а вот объяснить,
почему запрет дешевле, чем придуманная семантика копии, придётся словами.
