# Материалы занятий

По каталогу на занятие: `1.1/`, `1.2/` и так далее. Внутри бывает три вида
содержимого, и не у каждого занятия есть все три.

**`tests/` — выданные тесты.** Те самые, про которые в постановке написано
«довести до состояния „проходит выданные тесты“». Они же прогоняются при сдаче.

Подключаются при конфигурации проекта, без правки вашего `CMakeLists.txt`
и без перечисления наборов руками — по номеру занятия:

```bash
cmake --preset windows -D NANO_EDR_LESSON=1.1
```

Какие наборы действуют на каком занятии — в `lessons.cmake` рядом. Набор
прошлого занятия обычно остаётся подключённым: рефакторинг, задевший чужое,
обязан провалить его сразу. Уходит он только тогда, когда занятие меняет сам
контракт, который тот набор проверял; каждый такой случай в `lessons.cmake`
назван причиной.

Каждый каталог самодостаточен: `CMakeLists.txt` для подключения, `README.md`
с описанием контракта и эталоны. Начинайте с `README.md` — в нём написано,
что именно тесты фиксируют, а что оставляют на ваше усмотрение.

**`exercise/` — отдельная программа.** Примитив занятия или стенд для замера:
собирается вручную одной командой, в проект не входит и на сдачу не влияет.
Что с ней делать, написано в `README.md` рядом.

**`handout/` — выдано готовым.** Код, который не надо писать: копируется
в `src/` вашего проекта и дальше живёт как ваш — вы его правите на следующих
занятиях. Такое бывает редко и всегда с объяснением, почему занятие не тратится
на это; объяснение — в `README.md` рядом с файлом.
