# Тесты занятия 1.2

Две группы: окно последних событий (`list_tests.cpp`) и разбор строки журнала
(`parse_tests.cpp`).

## Как подключить

```bash
cmake --preset windows -D NANO_EDR_LESSON=1.2
cmake --build --preset windows
ctest --preset windows
```

На Linux вместо `windows` — `linux`. Набор 1.1 остаётся подключённым намеренно:
он фиксирует формат вывода детектов, и то, что он зелёный после переписывания
внутренностей, и есть доказательство, что контракт вывода не поехал.

Правки в вашем `CMakeLists.txt` не нужны. Тесты линкуются с библиотекой
`nano_edr_core`, а она собирается сама из всех `.cpp` в `src/`, кроме
`main.cpp`. Пока таких файлов нет, набор 1.2 **не соберётся**: компоновщик
скажет `unresolved external symbol` (на Linux — `undefined reference`)
на каждую функцию из заготовок. Это стартовое состояние занятия, а не поломка
комплекта.

Что именно должно быть реализовано и с какими подписями — в постановке
занятия (`practice/1.2.md`).

## Обязательно прогнать под санитайзером

Один из тестов — «тысяча элементов освобождается деструктором» — под обычной
сборкой не проверяет ничего. Он и не должен: утечку и двойное освобождение
видит не тест, а санитайзер.

```bash
cmake --preset asan-windows -D NANO_EDR_LESSON=1.2
cmake --build --preset asan-windows
ctest --preset asan-windows
```

На Linux — `asan`, и там же полнее: у GCC и clang это ASan и UBSan, у MSVC
только ASan.

Критерий занятия — «`-fsanitize=address,undefined` чист». Зелёный `ctest`
без санитайзера этого не показывает.

## Чего тесты не проверяют, но спросят на паре

**Рекурсию при освобождении.** Если не написать деструктор списка явным
циклом, цепочка `unique_ptr` разбирается рекурсией: список уничтожает голову,
та — своё поле `next`, и так до конца. Тесты здесь до тысячи узлов, так что
рекурсивная версия их пройдёт. Это не значит, что она верна.

**Расхождение `size` и длины цепочки.** Тесты считают узлы отдельно
(`CountNodes`) и сравнивают с полем `size` именно поэтому: поле, за которым
никто не следит, расходится с реальностью на первом же вытеснении.
